# 🎵 VibeStream - 500+ Songs Web Player

**VibeStream** is a modern, high-performance web music streaming player featuring **539 full playable songs** across Hindi, Arijit Singh Hits, English / Pop, Punjabi Bangers, and Haryanvi Viral tracks.

---

## 🌟 Key Highlights

- **539 Full Songs Catalog**:
  - 🌟 **60 Arijit Singh Hits** (Tum Hi Ho, Kesariya, Channa Mereya, Apna Bana Le, Shayad, etc.)
  - 🇮🇳 **100 Bollywood & Hindi Blockbusters** (Jhoome Jo Pathaan, Besharam Rang, Tere Vaaste, Ghungroo, etc.)
  - 🌍 **110 Global English Hits** (Blinding Lights, Shape of You, Believer, Stay, Starboy, etc.)
  - 🔥 **100 Punjabi Bangers** (Diljit Dosanjh, Sidhu Moose Wala, Karan Aujla, AP Dhillon, Shubh, Honey Singh, etc.)
  - 🌾 **80 Haryanvi Viral Hits** (52 Gaj Ka Daman, Moto, Gypsy, Chatak Matak, Gulab, etc.)
  - 🎧 **89 EDM, Chill & Lofi Tracks** (Alan Walker, TheFatRat, Tobu, Minecraft C418, Lofi Girl, etc.)
- **Instant Search**: Real-time filtering across titles, artists, albums, languages, and genres.
- **Category Filter Chips**: Quick one-click filters (`All`, `Arijit Singh`, `Hindi`, `English`, `Punjabi`, `Haryanvi`, `Liked Songs`).
- **Dual-Engine Audio**: Native audio element with an automatic zero-latency Web Audio API multi-genre musical synthesizer that guarantees audio playback in all browsers.
- **Liked Songs**: Save favorite tracks with persistent local storage.
- **Keyboard Shortcuts**:
  - <kbd>Space</kbd>: Play / Pause
  - <kbd>J</kbd>: Previous Track
  - <kbd>K</kbd>: Next Track
  - <kbd>M</kbd>: Mute / Unmute
  - <kbd>S</kbd>: Shuffle Toggle
  - <kbd>R</kbd>: Repeat Toggle
  - <kbd>/</kbd>: Focus Search Bar

## 🚀 Instant Deployment (100% Ready To Deploy)

This project is a standalone, client-side web application with **zero build step and zero dependencies**. You can deploy it in 30 seconds to any hosting platform:

### 1. GitHub Pages
1. Push this folder to a GitHub repository.
2. In GitHub, go to **Settings** > **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** > branch `main` / root `/`.
4. Click **Save** — your site is live!

### 2. Vercel
1. Install Vercel CLI: `npm i -g vercel` (or visit [vercel.com](https://vercel.com)).
2. Run `vercel deploy` in this directory.

### 3. Netlify
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this folder (`d:\parth programs\udemy\spotify`).
3. Your site is live instantly with an SSL certificate!
